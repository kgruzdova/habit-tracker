# ТЗ: Личный трекер привычек

## 1. Общие сведения

| Параметр | Значение |
| --- | --- |
| Тип продукта | Личный трекер привычек (используется только владельцем, регистрация закрыта для других) |
| Формат | Адаптивный сайт (не PWA), мобильная навигация — боковое бургер-меню |
| Хранение данных | Локально в браузере (`localStorage`), без сервера и базы данных |
| Стек | React + Vite + TypeScript |
| Целевые разрешения | Десктоп 1920 px, мобильный 360 px (без горизонтального скролла) |
| Темы | Светлая и тёмная, переключение в настройках |
| Дизайн-стиль | Минимализм, скруглённые карточки, тёплый акцентный цвет, шрифт Inter (системный фолбэк) |
| Отметка выполнения | Чекбокс; единица измерения — только для отображения цели |
| Порядок работ | Этап 1 — ядро, Этап 2 — данные и мотивация, Этап 3 — витрина |

## 2. Функциональные требования

### 2.1. Входная зона (витрина)
- **Лендинг** — Hero-блок, раздел «как это работает», ключевые возможности, пример дашборда (скриншоты), преимущества, футер. Помечено, что это личный трекер для дисциплины и укрепления привычек.
- **Вход** — форма логин + пароль, кнопка входа, ссылка на восстановление пароля, ссылка на регистрацию.
- **Регистрация** — форма (логин, email, пароль, подтверждение пароля), кнопка, ссылка на вход.
- **Восстановление пароля** — поле email, инструкция по сбросу, подтверждение отправки.
- **404** — страница для несуществующих маршрутов.

### 2.2. Today (дашборд)
- Приветствие с обращением по имени.
- Текущая дата.
- Прогресс-бар «выполнено X из Y».
- Список привычек на сегодня с чекбоксами; возможность поставить отметку за текущий и прошлые дни.
- Кнопка быстрого добавления привычки.
- Блок «Лучше, чем вчера» (мягкие напоминания и сравнение).
- Блок «Статистика в виде пользы» (перевод прогресса в понятные единицы).

### 2.3. Все привычки
- Список всех созданных привычек.
- Фильтр: активные / архивные.
- Текущая серия (стрик) крупными цифрами и горящей иконкой: «30 дней подряд!», «Выполняется: 7/7 дней на этой неделе».
- Счётчик пропусков: «У вас осталось 2 пропуска в этом месяце».
- Иконка и цвет привычки.
- Действия: редактирование, удаление, архивация.

### 2.4. Создание привычки
Поля формы:
- Название.
- Иконка и цвет.
- Периодичность: ежедневно / по дням недели / X раз в неделю.
- Напоминание (время).
- Единица измерения.
- Лимит пропусков в месяц (поле «сколько раз можно пропустить»).

### 2.5. Редактирование привычки
Та же форма, что и при создании, с предзаполненными данными.

### 2.6. Категории привычек
- Список категорий с иконками.
- Категории по умолчанию: Здоровье, Работа, Образование, Спорт, Питание, Дом, Вредные привычки (отказ / контроль), Творчество, Сон.
- Создание категории.
- Редактирование категории.

### 2.7. Календарь / история
- Просмотр выполненных привычек по дням.
- Тепловая карта: интенсивность по количеству выполненных привычек за день.
- Возможность отметить или исправить выполнение за прошлые дни.

### 2.8. Статистика привычки
- Текущая серия.
- Лучшая серия.
- Процент выполнения за неделю / 15 дней / 30 дней.
- График выполнения по дням / неделям.

### 2.9. Общая статистика
- Общая активность за всё время.
- Самые успешные привычки.
- Лучший день / неделя / месяц.
- Диаграммы.

### 2.10. Профиль и настройки
- Смена имени.
- Переключатель светлой / тёмной темы.
- Экспорт данных.
- Удаление всех данных.
- Включение / выключение уведомлений (push, email).

## 3. Нефункциональные требования
- Отсутствие горизонтального скролла на ширине 360 px.
- Растровые шрифты без внешних зависимостей либо локальный Inter.
- Состояние сохраняется между перезагрузками (localStorage).
- Типизация на TypeScript, прохождение линтера и сборки без ошибок.

## 4. Маршруты

| Маршрут | Экран |
| --- | --- |
| `/` | Лендинг |
| `/login` | Вход |
| `/register` | Регистрация |
| `/recover` | Восстановление пароля |
| `/app/today` | Дашборд Today |
| `/app/habits` | Все привычки |
| `/app/habits/new` | Создание привычки |
| `/app/habits/:id/edit` | Редактирование привычки |
| `/app/categories` | Категории |
| `/app/calendar` | Календарь / история |
| `/app/stats` | Общая статистика |
| `/app/stats/:id` | Статистика привычки |
| `/app/settings` | Профиль и настройки |
| `*` | 404 |

## 5. Этапы работ

**Этап 1 — ядро**
1. Каркас проекта, темы, бургер-навигация, раутинг.
2. Модель данных и хранилище.
3. Today: прогресс-бар, чекбоксы за сегодня и прошлые дни, быстрое добавление.
4. Создание / редактирование / архивация / удаление привычек.
5. Список привычек со стриком и счётчиком пропусков.
6. Календарь с тепловой картой и правкой истории.

**Этап 2 — данные и мотивация**
7. Категории: список, создание, редактирование.
8. Мотивационные блоки на Today.
9. Статистика привычки и общая статистика с графиками.
10. Настройки: имя, тема, экспорт, удаление данных, тумблеры уведомлений.

**Этап 3 — витрина**
11. Лендинг.
12. Вход, регистрация, восстановление пароля (фиктивные, без реальной авторизации).
13. 404.

## 6. Что осознанно не входит в объём
- Реальная авторизация, сервер, синхронизация между устройствами.
- Реальные push- и email-уведомления (только переключатели в настройках).
- PWA-манифест и нижняя навигация — вместо этого бургер-меню.
- Регистрация для сторонних пользователей.
